# Gesture Music 🎵

A computer vision project that turns hand gestures into musical notes.

## Current Progress

- [x] Webcam input
- [x] Hand detection
- [x] 21-point hand landmark tracking
- [ ] Gesture recognition
- [ ] Gesture-to-note mapping
- [ ] Audio generation
- [ ] Melody mode
- [ ] Singing mode

## Tech Stack

- Python
- OpenCV
- MediaPipe
